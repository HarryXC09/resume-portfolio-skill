# 素材指南

先运行 `node scripts/intake.mjs`。目录可以提前创建，所有用户原件默认 Git ignored。

## 简历与机构

inputs/resume 放主要简历一份（PDF / DOCX / TXT / MD）；存在多个版本时确认采用哪版。机构 Logo 放 inputs/logos，建议透明 PNG 或 SVG，文件名注明学校/单位；不要自动从网上选一个相似 Logo。照片放 inputs/photos，建议正面和侧面各一张，高清、无遮挡。

## 动作视频

建议 16:9、1080p 以上、25/30/60 fps，每条 4–8 秒。绿幕均匀布光，人物与背景保持距离、避免绿衣和绿反光，镜头固定，人物/手部不要越出画面。动作轻缓，开头结尾姿态相近便于循环；头发、白衣边缘尤其需要检查。可提供更多素材，但不能靠数字自动推断素材内容。

| 文件 | 默认页面位置 | 镜头建议 |
| --- | --- | --- |
| 01.mp4 | 首屏 | 正面半身或站姿，轻微自然动作 |
| 02.mp4 | 联系区左 | 一组符合真实职业的工作动作 |
| 03.mp4 | About | 侧面或人物近景 |
| 04.mp4 | 实践轮播 | 电脑/桌前工作 |
| 05.mp4 | 联系区右 | 写字、阅读、整理资料 |
| 06.mp4 | 实践轮播 | 第二组专业动作 |
| 07.mp4 | 实践轮播 | 站姿看文件或第三组动作 |

三组（01、03、04）即可开始，并明确将其他位置复用或改照片；完整七组更丰富。以人物职业为准，不要求非医生模仿医疗操作。

运行 `node scripts/process-media.mjs --key=0x00d000 --similarity=0.22 --blend=0.08`，参数可调整。脚本保留原件，生成 public/videos/doctor-idle-NN.webm、public/posters/poster-NN.webp。doctor-idle 是保留的技术文件名，不表示人物职业。运行会重建对应派生文件。

如果只有照片，可处理为透明 WebP 放同编号 posters，并调整 Video 组件避免请求不存在的视频。不得暗中生成新人肖像动作；AI 生成需要用户明确选择且使用可用工具。

## 可选模型

模型放 inputs/models，Agent 根据语义选择并复制为 public/models/tumor-cell-web.glb（或同步调整 cell.js 的路径）。没有模型时 Research 当前显示降级文字；制作成品时应使用用户项目图片或调整布局，不留加载失败提示当作设计。
